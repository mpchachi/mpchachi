## Projects

**[Wildfire response with agents](#)** · HackSpain 2026
Emergency coordination built on HappyRobot agents. In the demo we simulated a fire a few kilometers from the venue. The agent detected it, set the affected radius and phoned everyone in the area.

**[NeuroTransa](https://github.com/mpchachi/steady-arc)** · SteadyArc Hackathon
Remote monitoring for stroke recovery. Eye tracking, EMG and grip sensors send data to an AWS backend that writes clinical reports with Bedrock.

**[Language Coach Analytics](https://github.com/mpchachi/projectEurope)** · Preply Hackathon 2026
Post-lesson dashboard for language teachers. Deepgram transcribes the class and Claude pulls out 12 teaching metrics, like CEFR level, errors and the moments where the student hesitates.

**[AnalistaMetal](https://github.com/mpchachi/AnalistaMetal)**
Checks supplier invoices against live aluminium (LME) and electricity (OMIE) prices to flag overcharges.
